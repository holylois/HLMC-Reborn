# License scope and third-party material

The root MIT license applies to original Holy Lois source code and documentation authored by the Holy Lois team. It does not relicense dependencies or assets owned by other authors.

- Downloaded mods, resource packs, shader packs, Minecraft/Java/.NET binaries and copied third-party source keep their original licenses and notices. A signed manifest authenticates a download; it does not grant copyright permissions.
- The Holy Lois name, logo and crown are reserved branding. See BRAND.md in the launcher repository. The code license does not grant permission to impersonate the project or use its branding as your own.
- Generated release binaries and historical source archives can contain third-party material. Review their separate notices and provenance; do not assume everything inside an archive is MIT.
- Add-on metadata declaring MIT describes the add-on's own code. Included libraries keep their separate license (for example JLayer is LGPL-2.1).
- New mod candidates require a compatible redistribution/download route before public inclusion. Punchy! currently permits inclusion in Modrinth/CurseForge modpacks but prohibits jar redistribution. Private compatibility downloads do not establish permission for a public custom-launcher release.

These files formalize the existing MIT declarations for original project code. A full dependency/asset inventory remains part of release review.

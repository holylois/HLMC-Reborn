# Reporting a security issue

Send suspected vulnerabilities privately to hello@holylois.com. Include the affected version, expected and
observed behaviour, and steps using generated test data. Do not post exploit instructions in public issues or
community chat, and do not include passwords, recovery codes, tokens, real player records or private backups.

The operator will review the report and coordinate a fix. This project does not offer a paid bounty or promise
a response deadline. For ordinary gameplay problems, use https://holylois.com/support.
